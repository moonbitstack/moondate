The four shapes

One moment, four meanings.

TOML names exactly these, and the difference is not decoration. Only Zoned is an instant; the other three need a zone before they can name one.

What it does

A calendar, and the text around it.

The calendar is the proleptic Gregorian one, exact over the whole range an integer holds. Everything else is about reading and writing it in the forms the wire expects.

Parse & format

Read a timestamp into one of four shapes, and write it back in the shape it was. A round trip through a document keeps every field.

Calendar arithmetic

Days, weekdays, year days, ISO week dates and ordinals. Add days or months and carry across boundaries without a table.

HTTP dates

Write the one form a Date header may take, and read the two obsolete forms a recipient must still accept.

ASN.1 time

UTCTime and GeneralizedTime, with the two-digit-year window a certificate uses — which is not the window HTTP uses.

strftime & strptime

The C89 directives, in both directions, so a format string reads back exactly what it wrote.

cron

Five fields, or six with seconds. Names, lists, ranges, steps and the shorthands — plus the answer to when it next fires.

Schedules

Ask a cron expression when it fires next.

Five fields as crontab(5) defines them, or six with seconds in front. Both 0 and 7 are Sunday. Day-of-month and day-of-week are or-ed when both are restricted.

cron

next firings

schedule.mbt
let now = @moondate.parse("2026-09-22T14:30:00Z")
@cron.parse("0 9 * * MON-FRI").next(now)   // Some(2026-09-23T09:00:00Z)
@cron.parse("@daily").next(now)            // Some(2026-09-23T00:00:00Z)
